- Kali checkpoint at 45 sec: 1 security question, same no-fail rule.
- End: score, Bolt Points for FINISHING ONLY, decimal/binary summary, 3 lines of code.
- Manual audio toggle only, no autoplay.
- Architecture: Game Loop, Input, UI, Level 1 rules SEPARATED. LEVELS registry with Level 1 active, placeholders for Level 2 Loop, Level 3 Cipher, Level 4 Echo Beat, Level 5 Hex. Do NOT build those yet.

PLAN 4 - LESSONS: WHAT WE TEACH
This is NOT hustle. NOT grind. NOT loot boxes. NOT streaks. NOT FOMO. NOT pay-to-win.
We teach:
1. BINARY - how computers count with 0 and 1
2. CODE - 3 lines behind the game they can read
3. AI - Ask Echo explains, does NOT do homework
4. SAFETY - Kali: which password is safest, should you click this link
5. PYTHON BASICS - the vital skill for next gen, taught as a tool
   Level 1: print(int("101", 2)) = 5  -> binary becomes a real number
   Level 2: for i in range(3): print("Echo says hi") -> loop
   Level 3: if password == "strong": print("Safe") else: print("Try again") -> if/else + safety
   Level 4: beat = [1, 0, 1, 1] -> lists + music
   Level 5: print(hex(255)) -> hex, one step up
   Rule: You write 3 lines, you see Echo do it, you save it, you check it.
