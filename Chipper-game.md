Build a single-file HTML5 game called "Jolt's Binary Race" for kids aged 7-12. A small blue furry robot runs along a track automatically. Bits (0s and 1s) fall from the top one at a time — catch them left to right to build the target number shown at the top (start with 1-bit targets 0 or 1, then 2-bit 0-3, then 3-bit 0-7). Correct catch: +100 points, chime, slot lights mint green. Wrong catch: no penalty, the robot shakes and a red cube robot pops up with a one-line hint. Every 15 seconds a gate asks one multiple-choice binary question; right answer = speed boost, wrong answer = one-line explanation and the gate opens anyway. 60-second run, then an end screen with score, Bolt Points, and the last number in decimal and binary. Black background, mint green #34F0A4, chunky readable text, no sound autoplay, works on a phone. No loot boxes, no streaks, no timers that punish the player.
